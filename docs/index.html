pyScripting

Supply Chain Data Toolkit — a Python automation pipeline that generates sample order data, validates and cleans it, loads it into SQLite, runs SQL-based analysis, and outputs a summary report.

Built with Python standard library only

What’s included

  • Sample data generation
  • Data cleaning and validation
  • SQLite loading and SQL analysis
  • Text report generation

Run the pipeline

python pipeline.py

Output files

  • outputs/cleaned_orders.csv
  • outputs/orders.db
  • outputs/summary_report.txt
